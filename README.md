# note-trend-collector

note・はてブから取得した記事を整理し、企画検討用のレポートをGmailで送るPythonツールです。売上や再生数を予測・保証するものではありません。

## 修復状況

この作業ブランチは修正候補です。Python 3.12で17項目のオフラインテストを実施済みですが、実際の収集、Claude API、Gmail送受信、定期実行は未検証です。
有料記事の本文と添付PDFには別構成の手順が残っているため、商品全体の修復完了を意味しません。

## 現在の実装

- note: タグごとに公開記事を取得し、公開範囲の見出し等を抽出します。手動メモを読み込む実装ではありません。取得先の仕様変更で動かなくなる可能性があります。
- はてブ: RSS取得後、キーワードで絞り込みます。設定件数までの候補に対してブックマーク数を取得します。サイト全体の人気ランキングではありません。
- 両媒体とも0件なら、API分析とメール送信を中止します。片方のみ取得できた場合は得られた範囲で出力します。
- AI分析には観測事実・企画仮説・未確認事項の分離を指示します。出力の正しさは人による確認が必要です。
- API未設定・失敗・出力打ち切りの場合は、AI分析ではない集計版だと明示します。
- メールに載せる外部テキストはHTMLとして解釈されないよう処理し、リンクはhttp(s)のみ許可します。

## 設定

GitHub ActionsではリポジトリのSecretsに次を設定します。値をコードや公開Issueへ貼らないでください。

| 名前 | 用途 |
| --- | --- |
| GMAIL_ADDRESS | 送信用Gmail |
| GMAIL_APP_PASSWORD | Googleのアプリパスワード |
| TO_EMAIL | 宛先。複数の場合はカンマ区切り |
| ANTHROPIC_API_KEY | AI分析を使う場合のAPIキー |

ローカルでは環境変数または.envを使います。.envはコミットしないでください。
CLAUDE_MODELは環境変数で変更できます。未指定時はコード内の既定値を使用します。
GitHub Actionsで変更する場合はworkflowのenvにも設定してください。

Googleアプリパスワードの利用条件は[Googleの公式案内](https://support.google.com/accounts/answer/185833)を確認してください。
API費用はモデル、入力・出力量、実行回数で変わります。このREADMEでは月額や無料クレジットを保証しません。利用前にプロバイダーの料金と支出上限を確認してください。

## 外部送信をしないテスト

    python -m pip install -r requirements.txt
    python -m unittest discover -s tests -v

テストではHTTP、API、SMTPをモック化しています。実サービスへの接続成功を示すテストではありません。

## 実行

    python main.py

これは実際の収集・API利用・メール送信を行うコマンドです。設定値と送信先を確認してから実行してください。
GitHub ActionsのWeekly Trend Reportも同じ本番処理を実行します。
現在のcron設定は月曜00:00 UTC（09:00 JST）です。配信時刻の保証ではありません。
実行結果はActionsのログと受信メールで確認してください。
